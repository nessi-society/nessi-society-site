# Nessi Society

Page de présentation des créations logicielles originales de Nessi Society : des applis Android vendues en exemplaire unique, livrées clés en main avec leur code source et leurs droits d'exploitation.

## Contenu

| Fichier | Rôle |
| --- | --- |
| `index.html` | La page (un seul fichier, sans dépendance à installer) |
| `manifest.webmanifest` | Permet d'installer la page sur l'écran d'accueil comme une appli |
| `icon*.png`, `icon.svg` | Icônes de la page et de l'appli installée |

## Mise en ligne

La page fonctionne telle quelle sur GitHub Pages : **Settings › Pages › Deploy from a branch › `main` / `(root)`**.
